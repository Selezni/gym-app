# Тренировки — мини-приложение для Telegram

Трекер тренировок в зале: своя программа из списка упражнений, запись весов и повторов, таймер отдыха, подсказки по прогрессии, счётчик белка.

Фото упражнений: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (The Unlicense, общественное достояние).
